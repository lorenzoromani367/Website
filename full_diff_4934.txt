    Wire up bar/fluoxetine/licking/moon/plastic/tower/compression as real projects
    
    Adds six new projects (Bar, Fluoxetine, Licking, Moon, Compression) and
    replaces the Tower/Plastic placeholders with real photos, using the
    files pushed directly to their images/ subfolders. Renamed files to the
    site's existing convention (lowercase, hyphenated, no spaces) and
    re-encoded the oversized ones (several were 5-8MB, camera-native
    resolution) to match every other project's images: max 2200px on the
    long edge, JPEG quality 85, EXIF-orientation baked in then stripped —
    sizes dropped by 80-95% with no visible quality loss (e.g. bar-1.jpg:
    8.0MB -> 625KB).
    
    These were previously "words" added via the home-page +/free-text
    feature, which only exists in the browser that created them — not
    something I can wire real files into from the repository. Promoting
    them to actual PROJECTS entries is what makes them permanent and
    visible to every visitor. Added a one-time migration that removes any
    locally-saved home word whose text matches one of these seven names
    (case-insensitive), so anyone who already had it as a word doesn't end
    up with a duplicate entry pointing at the old, now-empty word page.
    
    Also fixed a real bug behind the "Compression" home-word text getting
    clipped (e.g. showing "Comp" instead of "Compression"): the input had a
    fixed/min-width that never grew with its content, unlike a plain link.
    It's now sized in JS from the exact rendered width of its own text
    (measured via a hidden mirror span), synced on every keystroke, so no
    word can ever be cut off regardless of length.
    
    Bumped the asset cache-busting version to v=6.
